# Game Cartridges

Web edition of Alberto Hojel's X Article, published at `https://albertohojel.com/work/game-cartridges/` with the approved homepage upgrade.

The article was captured from Alberto Hojel's public X Article, preserving its wording, formatting, and footnotes. Browser verification found an exact match after whitespace normalization: 18,036 characters. The More demos tab contains six follow-up posts, including their quoted posts where present.

`sources.json` records the original article/video URLs, post IDs, exact reply text, and media dimensions. Article text came from the rendered X page; follow-up video URLs were resolved through the public FxTwitter API.

`media/` contains four article videos, six follow-up videos, their posters, and three diagrams. Highest-resolution MP4 variants exposed by the source were retained without re-encoding. All ten files passed ffprobe checks; the article's first video also played successfully in the browser at 1694 x 1480.

The videos are served directly by GitHub Pages. Each file is below GitHub's 100 MiB single-file limit; together they are about 297 MiB. Consider object storage if sustained video traffic grows substantially.
